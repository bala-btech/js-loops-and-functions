# ⚡ JavaScript Foundations: Loops & Functions

A beginner-friendly collection of essential JavaScript logic, tracking fundamental control structures, arrow functions, and mathematical loop operations.

---

## 🚀 Solved Problems Reference

### 1) Even or Odd
An arrow function that uses the modulo operator (`%`) to determine if a number can be divided by 2 with zero remainder, returning either `"Even"` or `"Odd"`.

### 2) Result Evaluator — Pass or Fail
A standard function that processes exam marks. It includes validation guards to log `"Invalid marks"` and return `null` for numbers outside the standard 0–100 range, while cleanly mapping valid scores to `"Pass"` or `"Fail"`.

### 3) Maximum Finder — Largest of Three Numbers
An arrow function that calculates the maximum value among three parameters using sequential logical AND (`&&`) comparison chains without relying on built-in math helpers.

### 4) Accumulator — Sum from 1 to N
A function utilizing a standard `for` loop to incrementally aggregate and accumulate numbers starting from 1 up to a specified variable `n`.

### 5) Multiplication Table Generator
A loop-driven printing function that uses template string concatenation to output the traditional 1 to 10 mathematical multiplication table for any given integer.

### 6) Digit Counter — Number Length Finder
A pure mathematical approach using a `while` loop and `Math.floor()` division by 10 to strip numbers down and count their total digit length without transforming the data into a string.

### 7) Number Reverser
An algebraic loop execution that dynamically isolates the final digit of an integer using a modulo 10 operation (`% 10`), shifts the existing base, and builds out a perfectly reversed version of the number.

### 8) Factorial Engine
A classic `for` loop structure configured to compute the factorial of a target number ($n!$) by starting at 1 and multiplying sequentially up to the target index.

### 9) Prime Validator
A validation function that checks divisibility from 2 up to the number itself using a loop. It flags factors early by returning `false` if an even division occurs, and returns `true` if no factors are discovered.

### 10) Pattern Builder — Right-Angled Triangle
A nested loop implementation that structures a geometric right-angled triangle pattern.
